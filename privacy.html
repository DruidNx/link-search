Privacy policy

Last updated: October 31, 2026

link-search is a personal tool that runs only on its owner's computer. This policy explains how it handles data obtained from Google through the YouTube Data API.

What data is accessed

With your consent, link-search requests read-only access to your YouTube account (https://www.googleapis.com/auth/youtube.readonly). It reads only the list of videos you have liked, along with public information about those videos: title, description, channel, tags, duration, view count and thumbnail.

How the data is used

The data is used only to build a private search index of your liked videos on your own computer, so you can search them alongside your other saved links. It is not used for advertising, profiling or any other purpose.

Storage

All data, including the OAuth refresh token, is stored locally on the computer where link-search runs. Nothing is sent to any server operated by the developer; the only network requests are to Google's own APIs.

Sharing

Data obtained from Google APIs is not sold, transferred or shared with anyone.

Google API Services User Data Policy

link-search's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. link-search uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

You can revoke link-search's access at any time at myaccount.google.com/permissions. Deleting link-search's local data/ folder removes all stored data and tokens.

Contact

Questions: open an issue at github.com/DruidNx/link-search.
