link-search

link-search is a personal, self-hosted tool that lets its owner search the links they have saved across services (GitHub stars, Hacker News, Reddit and YouTube likes) using natural language.

It runs entirely on the owner's own computer. With the owner's permission it reads the list of YouTube videos they have liked (read-only access through the YouTube Data API) so those videos can be included in their personal search index.

It is not a public service: there are no user accounts, and nothing is hosted or shared online.
